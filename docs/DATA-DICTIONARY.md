# 访视与冻结定义

样例均为虚构编号，无身份信息。受试者入组日期由subjects表唯一确定，记录中的入组基准必须完全一致。采样日期和入组日期均转为Asia/Shanghai日历日期，差值为访视日；时刻先统一UTC。
方案选择按当前受试者assignment和该次发生时刻查半开生效窗，匹配必须唯一，不能使用全局最新方案。v1访视V1=[5,10)、V2=[12,17)；v2为[6,11)、[13,18)。受试者00001于10月10日转v2，其他受试者仍用v1。
PRIMARY计入访视完成，RETEST只替代该次测量值。首次记录必须唯一且在访视窗内。缺首次访视、重复首次和窗外访视均阻断，复检不能填补漏访或消除原偏离。
复检须引用同受试者同访视的PRIMARY，晚于原采样且不超过72小时，版本必须更高。同最高版本复检冲突时保留原结果并阻断。所有检验值以mg/dL输出，g/L乘100。
中心豁免（context.waivers）只可改变窗外访视的锁库后果，不能消除或改写偏离本身。豁免须同时满足：scope=VISIT且subject、visit与该次偏离逐一匹配（scope=SUBJECT仅覆盖受试者、未指定访视，不能授权具体窗外偏离）；审批时刻approved_at不晚于该次访视采样时刻（晚于访视的审批不能追溯授权）。漏访MISSING_PRIMARY、重复首次DUPLICATE_PRIMARY不属于豁免受理范围，复检亦不能伪填。同一waiver_id重复登记按首次处理，记WAIVER_DUPLICATE，重试不新增放行；结构或审批时刻无效记WAIVER_MALFORMED且不进入可授权清单。
每条应访视产出一条统一裁决visit_decisions（受试者×访视），字段含record_id、line（原始访视行号）、window_code、deviation_code、waiver_id、decision（通过/豁免放行/阻断）、reason_code、reason、blocks_lock。访视排窗、偏离复核、锁库检查、冻结归档共用该同一结论；豁免放行项blocks_lock=false但偏离仍留痕。锁库阻断数=仍阻断偏离+复检问题+采信隔离，且行守恒成立才可锁库。冻结包含豁免清单、豁免登记裁决waiver_reviews与统一裁决（归档包waivers.json），封存seal覆盖以上依据。
锁库须所有规定访视完成，无未被授权的偏离、复检问题和隔离行。冻结包包含每条选定结果、原始行号、方案版本、访视窗与豁免审批依据。重算在持久化前完成，失败时不写入，库内保留旧版锁库结论；同输入与规则版本批号不变，同一豁免重试不新增放行。此工具只验证试验数据完整性，不做诊断判断或生产锁库。
